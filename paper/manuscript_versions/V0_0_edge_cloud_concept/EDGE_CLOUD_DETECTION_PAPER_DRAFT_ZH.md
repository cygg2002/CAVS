# 面向低功耗智能摄像头的成本感知端云协同目标检测方法

> 当前版本：中文小论文初稿模板  
> 投稿方向：Journal of Real-Time Image Processing / Machine Vision and Applications 通用结构  
> 状态：边写边补实验  
> 更新时间：2026-06-16

## 摘要

针对低功耗边缘摄像头目标检测精度受限、全量云端检测通信开销较高的问题，本文提出一种成本感知的端云协同目标检测方法。该方法以轻量化检测模型作为端侧实时检测器，以更大规模检测模型作为云端复核器，并设计帧级与 ROI 级双粒度上传机制。为避免低价值样本造成无效通信，本文进一步构建学习型上传决策器，根据端侧检测置信度、目标尺度、图像复杂度和上传代价估计云端复核收益，从而实现检测精度、通信带宽、端到端延迟和计算量之间的动态权衡。实验结果表明，在 COCO 数据集上，所提方法相比端侧单模型显著提升检测精度，并在减少上传比例和平均计算量的同时保持较高检测性能。基于 T41 摄像头平台的链路实验进一步验证了该方法在低功耗智能摄像头场景中的部署可行性。

关键词：端云协同；目标检测；边缘智能；智能摄像头；上传决策；YOLO

## 1. 引言

随着智能摄像头、无人值守监控、野外感知和移动边缘设备的发展，目标检测模型越来越多地部署在资源受限的端侧设备上。端侧部署能够降低响应延迟并减少隐私风险，但轻量化模型受限于算力、存储和功耗，通常存在误检、漏检和分类错误等问题。与此相对，云端模型具有更强的计算资源和更高检测精度，但如果将每一帧图像全部上传云端，会带来较高的带宽消耗、网络延迟和云端计算成本。

端云协同推理为解决上述矛盾提供了一种可行路径。端侧模型负责实时检测与初步判断，云端模型仅对端侧不确定或高价值样本进行复核。然而，现有简单协同策略通常依赖固定置信度阈值或周期性关键帧上传，难以同时兼顾检测收益和传输代价。特别是在目标检测任务中，上传对象既可以是整帧图像，也可以是局部 ROI 区域；不同上传粒度对应的精度收益、带宽开销和融合方式均不同。

为此，本文提出一种面向低功耗智能摄像头的成本感知端云协同目标检测方法。该方法利用端侧检测结果提取图像级和 ROI 级特征，通过学习型上传决策器估计云端复核收益，并显式引入上传数据量、网络状态和计算代价，从而选择整图上传、ROI 上传或不上云。云端模型完成高精度检测后，系统根据上传类型对端侧和云端检测结果进行融合，输出最终检测结果。

本文主要贡献如下：

1. 提出一种面向低功耗智能摄像头的端云协同目标检测框架，将端侧轻量检测、云端强模型复核和结果融合统一到一个完整系统中。
2. 设计帧级与 ROI 级双粒度上传机制，使系统能够根据场景难度选择整图复核或局部复核，降低无效上传。
3. 构建成本感知学习型上传决策器，将预期检测收益与通信代价联合建模，避免仅依赖人工阈值造成的低价值上传。
4. 在 COCO 数据集和 T41 摄像头链路上从检测精度、上传量、计算量和端到端延迟等维度验证所提方法的有效性。

## 2. 相关工作

### 2.1 轻量化目标检测

本节待补充 YOLO 系列、轻量化检测模型、端侧部署、模型压缩和量化相关工作。

拟写要点：

- YOLO 系列在实时目标检测中的优势；
- 轻量模型适合端侧实时检测，但精度通常低于大模型；
- 端侧部署需要考虑输入尺寸、量化、NPU/CPU/GPU 适配。

### 2.2 端云协同推理

本节待补充 edge-cloud inference、selective offloading、cloud-assisted perception 相关工作。

拟写要点：

- 端侧全本地推理延迟低但精度有限；
- 云端全量推理精度高但通信成本大；
- 选择性上云可在精度和资源之间取得折中；
- 现有工作多集中于分类或整图上传，对目标检测中的 ROI 级协同考虑不足。

### 2.3 资源感知视觉检测

本节待补充低带宽、弱网、实时视频分析、ROI 上传、关键帧上传相关工作。

拟写要点：

- 视频流中相邻帧冗余高；
- 小目标、低置信目标、贴边目标更容易出错；
- 固定规则具有可解释性，但难以适应不同场景和网络状态；
- 学习型决策可以从验证集上学习“哪些样本值得上云”。

## 3. 系统总体架构

本文系统由端侧检测模块、上传决策模块、云端复核模块和结果融合模块组成。

```text
T41 + 摄像头
  -> 图像采集与编码
  -> 端侧轻量检测模型
  -> 图像级/ROI级特征提取
  -> 成本感知上传决策器
       -> 不上传：直接输出端侧结果
       -> 整图上传：云端 YOLO26x 复核
       -> ROI 上传：云端局部区域复核
  -> 结果融合
  -> 返回检测框/告警/带框图像
```

端侧模块负责实时性，云端模块负责高精度复核，上传决策模块负责在精度收益和传输代价之间进行权衡。

### 3.1 端侧检测模块

端侧检测模块部署轻量化检测模型。算法实验中使用 YOLO26s 作为端侧模型，真实低功耗摄像头链路中使用 T41 平台完成图像采集、JPEG 编码和网络上传。若 YOLO26s 完成 T41 NPU 适配，则端侧检测也在 T41 上执行；若 T41 NPU 适配未完成，则论文中应如实区分算法验证平台和摄像头链路平台。

端侧输出定义为：

```text
edge_boxes = {b_i = (x1, y1, x2, y2, c_i, s_i)}
```

其中 `(x1, y1, x2, y2)` 为检测框坐标，`c_i` 为类别，`s_i` 为置信度。

### 3.2 云端检测模块

云端部署 YOLO26x 作为高精度检测模型。云端接收端侧上传的整图或 ROI 图像，同时接收端侧检测框、上传类型、ROI 坐标、原始图像尺寸和上传决策分数等元数据。

云端输出：

```text
cloud_boxes = CloudDetector(upload_image)
```

当上传类型为 ROI 时，云端检测框需要根据 ROI 左上角偏移映射回原图坐标。

### 3.3 端云传输模块

端云传输模块包含图像编码、元数据封装、上传队列、网络传输和返回结果解析。为了降低通信开销，建议采用 HTTP multipart 或 gRPC 传输，避免 base64 带来的额外编码膨胀。

上传元数据包括：

```text
frame_id
timestamp
payload_type: full_frame / roi
orig_shape
crop_xyxy
edge_boxes
p_gain
expected_gain
decision_score
jpeg_quality
```

### 3.4 结果融合模块

结果融合根据上传类型执行不同策略：

- 不上传：最终结果直接使用 `edge_boxes`；
- 整图上传：采用云端检测结果或端云融合结果；
- ROI 上传：将 ROI 云端检测框映射回原图后，对对应端侧框进行替换、删除或补充，并执行类别感知 NMS。

## 4. 方法设计

### 4.1 图像级与 ROI 级特征提取

图像级特征用于判断整帧是否值得上传，包括图像复杂度、端侧检测数量、检测覆盖率、置信度统计、小目标比例、低置信目标比例和贴边目标比例等。

ROI 级特征用于判断某个局部目标区域是否值得上传，包括目标置信度、面积占比、是否小目标、是否贴边、目标中心位置、宽高比、图像复杂度和检测覆盖率等。

### 4.2 成本感知上传决策

本文将上传决策建模为收益与代价的联合优化问题。对候选上传任务，定义决策分数：

```text
S = P_gain * G_exp - λ * C_upload
```

其中，`P_gain` 表示上传后可能提升检测结果的概率，`G_exp` 表示预期检测收益，`C_upload` 表示上传代价，`λ` 为代价权重。

上传代价可表示为：

```text
C_upload = payload_kb / 100
```

在真实网络环境中，可进一步扩展为：

```text
C_upload = payload_kb / 100 * (10 / uplink_mbps) * (1 + queue_len) * (1 + RTT_ms / 100)
```

决策规则为：

```text
if frame_probability >= frame_threshold and frame_score > 0:
    upload full frame
elif roi_probability >= roi_threshold and roi_score > 0:
    upload top-k ROI
else:
    no upload
```

### 4.3 学习型上传决策器

学习器由四个轻量头组成：

```text
frame_model: 整图上传收益概率预测
frame_value_model: 整图上传收益大小预测
roi_model: ROI 上传收益概率预测
roi_value_model: ROI 上传收益大小预测
```

概率头采用逻辑回归，收益头采用线性回归。模型参数保存为 JSON 文件，端侧推理时只需要标准化、点积和 sigmoid，适合资源受限设备部署。

训练标签由上传前后检测效用差生成：

```text
utility = TP - fp_penalty * FP
gain = utility_after_upload - utility_before_upload
```

当 `gain > utility_margin` 时，该样本被标记为正样本。

### 4.4 ROI 生成与上传

ROI 由端侧检测框扩展得到：

```text
ROI = expand(edge_box, gain)
```

对小目标和贴边目标使用更大的扩展倍率，以保留必要上下文。ROI 裁剪后进行 JPEG 编码，并与元数据一起上传云端。

### 4.5 端云结果融合

ROI 上传时，系统首先将云端检测结果映射回原图坐标，然后与端侧目标框按 IoU 匹配：

- 若云端框与端侧框匹配，则使用云端框修正端侧框；
- 若云端未确认低置信端侧框，可删除该框；
- 若云端发现额外高置信目标，可补充到最终结果；
- 最后执行类别感知 NMS。

| Power | 端侧功耗，若 T41 可测则补充 |

初步分析方向：

## 7. 讨论

需要诚实讨论当前限制：

- ROI 分支当前收益仍有限；
- 学习器主要在 COCO 上训练，跨场景需要重新校准；
- T41 NPU 部署 YOLO26s 存在模型转换和算子适配风险；
- 当前端到端延迟需要更多真实网络实验；
- 云端模型选择、输入尺寸和融合策略仍有优化空间。

## 8. 结论

本文提出一种面向低功耗智能摄像头的成本感知端云协同目标检测方法。该方法通过端侧轻量检测、云端强模型复核和学习型上传决策，在检测精度、通信带宽、端到端延迟和计算成本之间取得折中。实验结果表明，所提方法能够在显著降低上传量和平均计算量的同时提升端侧检测性能。未来工作将进一步完善 T41 NPU 端侧部署、视频时序记忆和网络状态感知上传决策。
