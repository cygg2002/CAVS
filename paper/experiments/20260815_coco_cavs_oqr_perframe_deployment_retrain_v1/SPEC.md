# Spec: deployment-consistent COCO CAVS-OQR retraining

## Objective

Rebuild and retrain CAVS-Current-MAUR with the same one-image-per-request
inference contract used by the real edge-cloud system. This removes the
batch-neighbour-dependent rectangular shapes produced by `model.val(rect=True)`.

## Frozen protocol

- COCO fit=9,678, calibration=571, final=5,000.
- Frozen five folds and model seeds 20260809/10/11.
- Actions: Edge, Original, Q90, Current@640.
- Fusion: MAUR.
- Fixed-byte budgets: 10%, 25%, 40% of native JPEG bytes.
- Detection: conf=0.001, IoU=0.7, max_det=300, end2end=False.
- Edge/Original/Q90: single-image rectangular letterbox with scaleup=False.
- ROI: single-image deployment predictor, FP16, Current geometry, MAUR fusion.
- Q90/ROI codec: quality=90, optimize=True, subsampling=2.

## Required stages

1. Preflight and source hash audit.
2. Resumable per-image Edge/Original/Q90/ROI cache for all three roles.
3. Common role bundles and fold-contained contextual AP50-95 rewards.
4. Five-fold OOF plus full-fit CAVS training for three seeds.
5. Cached calibration/final evaluation and policy export.
6. Real 5,000-image HTTP run with the exported policy.
7. Cached-versus-HTTP parity audit.

## Success criteria

- A cache inference call accepts exactly one decoded image.
- Payload bytes and ROI geometry are generated by the same helpers used by the
  HTTP client.
- All 15,249 role images have complete, hash-checked cache shards.
- All 18 learner jobs finish without reusing an old checkpoint.
- Fixed-byte capacity is never exceeded.
- Cached and real HTTP AP differ by at most 0.005 at each budget; 0.003 is the
  preferred target.

## Boundaries

- Existing experiments are read-only.
- Public val2017 remains a post-hoc system evaluation, not a hidden final.
- No batch-shape replay is allowed.
